# Windmill 言語切り替え for Android

物理キーボード向けの言語切り替えアプリ。<br>
日本語と英語を、変換/無変換キーでキッチリ切り替えます。

Android ではOSの仕様上、入力欄が変わるたびに英語 / 日本語がころころ入れ替わってしまいます。画面キーボードではよくても、外付けキーボードだと不便を感じたことはありませんか?

このアプリは英語キーボードとして常駐して、標準にはない「言語切り替えキー」を提供します。OS上の「キーボード」ではなく「言語」を変えるのがポイントで、Androidでもキッチリ切り替えを実現(?)しました。日本語変換には、使い慣れたGboard等をそのまま使えます。

## しくみ

アプリはふたつの機能から構成されています。

- 英語用の IME: 画面キーボードを持たない IME
- ユーザー補助サービス: 専用キーを受けて IME を切り替え

| キー | 切り替え先 |
|--|--|
| 変換 (`KEYCODE_HENKAN`) | 日本語側の IME。既定は Gboard で、設定画面で変えられます |
| 無変換 (`KEYCODE_MUHENKAN`) | 英語用の IME (Windmill 英語) |

変換/無変換キー以外は素通りで何もしてないので IME というか微妙なところ。

## インストール

- 対応: Android 11 以降
- 配布: [リリースページ](https://github.com/cognitom/windmill-android/releases/latest)  

リリースページでAPKファイルをダウンロードして、Filesアプリなどから開きます。

※一時的に「許可」にしてインストールすることになると思います。インストール後は「許可」を外して構いません。

※Google Play版を公開予定 (たぶん)

### 設定手順 1. 制限付き設定を許可 (Android 13 以降)

1. 「設定」→「アプリ」→「Windmill 言語切り替え」でアプリ情報を開く
2. 右上の「︙」メニューから「制限付き設定を許可」

メニューの名前や場所は、メーカーや Android のバージョンで少し変わります。Android 12 以前では、この手順は要りません。

### 設定手順 2. ユーザー補助サービスを有効に

1. アプリ「Windmill 言語切り替え」を開き、「ユーザー補助の設定を開く」
2. 一覧から「Windmill 言語切り替え」を選択
3. スイッチをオンに

このサービスが受け取るのはキーボードのキー入力だけで、画面の内容は読みません。変換・無変換の2つのキーだけを受け止め、ほかのキーはそのままアプリへ届けます。[実際の実装はここ](https://github.com/cognitom/windmill-android/blob/main/app/src/main/kotlin/io/github/cognitom/windmill/KeySwitchService.kt)から確認できます。

### 設定手順 3. 英語用の IME を有効に

「Windmill 英語」が自動で有効になります。基本的には何もしなくてOKですが、Android 12以前や、アンインストールして入れ直す場合はキーボード設定を有効にしておきます。

1. アプリ「Windmill 言語切り替え」の「キーボードの設定を開く」
2. 「Windmill 英語」をオンに

アプリの設定画面で、ユーザー補助サービスと英語用の IME がどちらも「有効」になっていれば準備はできています。

### 設定手順 4. 日本語側の IME を選ぶ (任意)

変換キーで切り替える先は、既定では Gboard です。ほかの IME にしたいときは、アプリの設定画面の「日本語側の IME」で選びます。無効な IME は、キーボードの設定で有効にしてから選びます。
